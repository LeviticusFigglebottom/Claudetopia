# The cave forge meshes its signed-distance field with marching cubes, and
# `skimage.measure.marching_cubes` is the implementation it has always used
# (tools/interiors/cave_forge.py). It was missing from this list, so a clone that
# installed exactly what the file asked for could not build a single deep place --
# `./run.sh` calls the cave forge on a first run, so that is the whole game.

# fresh install gets a trimesh whose decimator raises ModuleNotFoundError on the first
# cave and on any house shell over 4 000 faces.
